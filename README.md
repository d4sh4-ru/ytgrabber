# README

Проект для загрузки видео с онлайн-платформ, написан ИСКЛЮЧИТЕЛЬНО в образовтельных целях для освоения wails (go + angular).

Работает на macOS, Windows и Linux.

### Установка

Готовые сборки лежат на странице [Releases](https://github.com/d4sh4-ru/ytgrabber/releases):

| Система | Файл |
|---|---|
| macOS (Apple Silicon и Intel) | `ytgrabber-<версия>-macos-universal.zip`: распакуйте и перенесите `ytgrabber.app` в «Программы» |
| Windows x64 / ARM | `…-windows-amd64-setup.exe` (установщик) или `…-portable.exe`, для ARM — `…-windows-arm64-…` |
| Linux x64 / ARM | `…-linux-amd64.tar.gz` / `…-linux-arm64.tar.gz`: распакуйте и запустите `./install.sh` (ставит в `~/.local`, без root) |

Сборки не подписаны. На macOS при первом запуске нужно снять карантин: `xattr -dr com.apple.quarantine /Applications/ytgrabber.app`. На Windows SmartScreen пропускает так: «Подробнее → Выполнить в любом случае». Контрольные суммы файлов лежат в `SHA256SUMS.txt` рядом со сборками.

### Требования

Для сборки:

- go версии ^1.25.0
- node версии ^24.11.1 (см. `.nvmrc`)
- wails CLI v2.13.0: `go install github.com/wailsapp/wails/v2/cmd/wails@v2.13.0`
- Linux: `libgtk-3-dev` и `libwebkit2gtk-4.1-dev` (Debian/Ubuntu), для воспроизведения видео — плагины GStreamer (`gstreamer1.0-plugins-good`, `gstreamer1.0-libav`)

Для работы приложения:

| Программа | Зачем                                    | macOS                 | Windows                        | Linux                                       |
|-----------|------------------------------------------|-----------------------|--------------------------------|---------------------------------------------|
| yt-dlp    | загрузка (обязательно)                   | `brew install yt-dlp` | `winget install yt-dlp.yt-dlp` | `pipx install yt-dlp`                       |
| ffmpeg    | склейка дорожек, mp3, обложки (обязательно) | `brew install ffmpeg` | `winget install Gyan.FFmpeg`   | `sudo apt install ffmpeg`                   |
| ffprobe   | длительность (идёт вместе с ffmpeg)      | —                     | —                              | —                                           |
| deno      | нужен yt-dlp для YouTube                 | `brew install deno`   | `winget install DenoLand.Deno` | `curl -fsSL https://deno.land/install.sh \| sh` |

Ставить их заранее не обязательно. Если чего-то не хватает, приложение покажет предупреждение с кнопкой «Установить автоматически». Это же можно сделать в «Настройки → Внешние программы». Программы скачиваются в папку данных приложения (`<данные>/bin`), права администратора не нужны. Перед установкой проверяется SHA-256, опубликованный источником. Источники:

- yt-dlp — официальные релизы [yt-dlp](https://github.com/yt-dlp/yt-dlp/releases);
- ffmpeg и ffprobe — сборки проекта yt-dlp [FFmpeg-Builds](https://github.com/yt-dlp/FFmpeg-Builds) для Windows и Linux, сборки [Martin Riedl](https://ffmpeg.martin-riedl.de) для macOS;
- deno — официальные релизы [Deno](https://github.com/denoland/deno/releases).

Программы, поставленные через пакетный менеджер, тоже подходят, и добавлять их в PATH не обязательно. Приложение само ищет их в PATH и в стандартных местах установки: Homebrew, MacPorts, WinGet, Scoop, Chocolatey, `~/.local/bin`, `/snap/bin`, а также рядом со своим исполняемым файлом. Если программа всё равно не находится, путь к yt-dlp и ffmpeg можно указать вручную: «Настройки → Внешние программы». Там же видны найденные версии и есть кнопка обновления yt-dlp.

### Разработка

```bash
wails dev
```

В dev-режиме база, лог и загруженные видео лежат в `./data` и `./downloads` внутри проекта — обе папки в `.gitignore`, их можно (иногда и нужно) удалять для сброса состояния.

Тесты:

```bash
go test -race ./...
cd frontend && npm test && npm run format:check
```

CI (`.github/workflows/ci.yml`) собирает приложение и прогоняет тесты на macOS, Windows и Linux.

### Структура

```
main.go                 точка входа: настройки окна Wails, встраивание frontend/dist
internal/
  app/                  бэкенд, который вызывает фронтенд (методы App привязаны Wails):
                        очередь загрузок, библиотека, настройки, отдача медиа, удаление данных
  model/                общие типы данных (из них генерируются TS-классы)
  storage/              SQLite: схема, миграции, запросы
  ytdlp/                аргументы yt-dlp, разбор его вывода, недокачанные файлы
  media/                обложки и длительность через ffmpeg/ffprobe
  tools/                поиск yt-dlp/ffmpeg/deno, версии, окружение дочерних процессов
  installer/            скачивание этих программ из GUI с проверкой SHA-256
  platform/             всё, что зависит от ОС: пути, процессы, файловый менеджер
  logging/              лог-файл
frontend/               Angular-приложение
build/                  иконки и шаблоны пакетов: macOS, Windows (NSIS), Linux (.desktop, install.sh)
```

`main.go` лежит в корне модуля, потому что `//go:embed` не видит файлы выше каталога пакета, а Wails собирает корневой пакет.

### Сборка

Чтобы собрать самостоятельно, установите зависимости и запустите

```bash
# macOS / Windows
wails build

# Linux (webkit2gtk-4.1, Ubuntu 22.04+ / Debian 12+)
wails build -tags webkit2_41

# Windows с установщиком (нужен NSIS)
wails build -nsis
```

Результат — в `build/bin`.

Кросс-компиляция под другую ОС не гарантирует рабочий билд данная проблема решена не будет, для тестирования рекомендуется собирать сразу на системе где и будет делаться тык-тык в программу.

Сборка для macOS не подписана и не нотаризована. Если скопировать `.app` на другой Mac, Gatekeeper его заблокирует, и нужно снять карантин:

```bash
xattr -dr com.apple.quarantine /Applications/ytgrabber.app
```

### Выпуск версии

Релиз собирается GitHub Actions (`.github/workflows/release.yml`) по тегу версии:

```bash
git tag v1.2.0
git push origin v1.2.0
```

Workflow прогоняет CI, собирает macOS universal, Windows amd64/arm64 (portable и NSIS-установщик) и Linux amd64/arm64. Затем он публикует релиз с файлами и `SHA256SUMS.txt`. Версия берётся из тега: она подставляется в приложение (`-ldflags -X ytgrabber/internal/app.Version=…`) и в метаданные пакетов. Тег с суффиксом (`v1.2.0-rc.1`) публикуется как pre-release. В локальных сборках вместо версии написано `dev`.

### Где лежат данные

| | База и лог | Загрузки по умолчанию |
|---|---|---|
| macOS | `~/Library/Application Support/ytgrabber` | `~/Movies/ytgrabber` |
| Windows | `%AppData%\ytgrabber` | `%UserProfile%\Videos\ytgrabber` |
| Linux | `~/.config/ytgrabber` | `XDG_VIDEOS_DIR/ytgrabber` (обычно `~/Videos/ytgrabber`) |

Папку загрузок можно сменить в настройках. Уже скачанное при этом остаётся доступным, потому что библиотека хранит полные пути к файлам. Точные пути к базе и логу показаны в «Настройки → О программе».

Если приложение больше не нужно, откройте «Настройки → Удаление данных → Удалить всё…». Будут удалены база, настройки, журнал, кэш встроенного браузера, программы, установленные из приложения, и недокачанные файлы. По желанию удаляются и все скачанные файлы из библиотеки. После этого приложение закроется, и останется только удалить само приложение. Посторонние файлы в папке загрузок не трогаются: папка удаляется, только если после очистки в ней ничего не осталось. Кнопка доступна и тогда, когда приложение не смогло запуститься из-за повреждённой базы.
