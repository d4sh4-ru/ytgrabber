# README

Проект для загрузки видео с онлайн-платформ, написан ИСКЛЮЧИТЕЛЬНО в образовтельных целях для освоения wails (go + angular).

### Требования

- go версии ^1.25.0
- npm версии ^24.11.1
- angular-cli версии ~21.2.19
- yt-dlp чем свежее тем лучше + он должен быть добавлен в PATH
- ffmpeg/ffprobe в PATH

### Разработка

```bash
wails dev
```

В dev-режиме база и загруженные видео лежат в `./data` и `./downloads` внутри проекта — обе папки в `.gitignore`, их можно (иногда и нужно) удалять для сброса состояния.

### Сборка

Проект не будет предоставлять бинарники программы для сборки установите зависимости и запустите 
```bash
wails build
```

Кросс-компиляция под другую ОС не гарантирует рабочий билд данная проблема решена не будет, для тестирования рекомендуется собирать сразу на системе где и будет делаться тык-тык в программу.

### Отказ от отвественности

Проект не связан с YouTube и другими платформами, чей контент можно скачать через yt-dlp. Использование ограничивается личными, некоммерческими и образовательными целями - соблюдение правил на использование платформ и авторских прав на скачанный контент остаётся на пользователе. Автор за возможные деструктивные действия пользователей данного кода НЕ НЕСЕТ!
